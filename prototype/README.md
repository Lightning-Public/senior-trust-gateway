# Prototype

첫 프로토타입은 전체 생활매니저가 아니다.

## P0 — Trust Check

검증할 흐름:

```text
문자/링크 입력
→ “무슨 내용인지” 쉬운 설명
→ 위험 신호 분석
→ 공식 확인 가능한 정보 확인
→ 🟢 괜찮음 / 🟡 확인 필요 / 🔴 하지 말 것
→ 필요 시 가족/신뢰원 확인 요청
```

## UX constraints

- 첫 화면에서 기능 메뉴를 많이 보여주지 않는다.
- 사용자는 “이거 괜찮아?”라는 방식으로 바로 시작할 수 있어야 한다.
- 전문 용어보다 행동을 알려준다.
- 위험 점수 숫자보다 이해 가능한 이유를 우선한다.
- 색상만으로 상태를 전달하지 않는다.
- AI가 모를 때 모른다고 말하고 다음 안전한 행동을 제공한다.
