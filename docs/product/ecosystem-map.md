# Ecosystem Map

이 문서는 경쟁과 연계를 혼동하지 않기 위한 초기 지도다. 실제 API·계약·약관 검증 전에는 연계 가능성을 확정하지 않는다.

## 1. Direct/adjacent competitors

### 범용 AI/통신·플랫폼 AI

전화, 메시지, 검색, 예약 등 생활 실행 기능이 빠르게 확대되고 있다.

전략: 범용 비서 기능 자체로 정면 경쟁하지 않는다. **사용자의 신뢰·권한·보호 레이어**에 집중한다.

### 시니어 안부/돌봄 AI

안부 확인, 위험징후 탐지, 지자체 관제 등은 인접 영역이다.

전략: 돌봄 관제 자체보다 디지털 행동의 신뢰 게이트웨이에서 시작한다.

### 실제 사람 기반 생활지원/병원동행

AI가 해결하기 어려운 물리적 업무를 수행한다.

전략: 장기적으로 경쟁자보다 `human escalation network` 후보로 본다.

## 2. Integration candidates

아래는 역할 범주이며 개별 서비스 연결은 공식 API/약관 검토 후 확정한다.

- 보안/피싱 검증 기관 및 서비스
- 공공서비스/전자정부
- 병원·약국·예약/동행
- 지도·교통
- 통신/메시징
- 가족/보호자 알림 채널
- 본인인증/전자서명
- 금융사기 보호 관련 공식 채널

## 3. Build vs connect

### 직접 가져가야 할 것

- 사용자별 권한 정책
- 위험도 판정 오케스트레이션
- Trust Circle
- 승인/에스컬레이션 프로토콜
- 생활 맥락 및 해결 이력
- 감사 가능한 행동 로그
- 시니어 친화적 설명/UX

### 가능한 한 외부에 맡길 것

- 범용 LLM 자체
- 지도/길찾기
- 공공 원천데이터
- 병원 예약망
- 결제망
- 이동/동행 인력망
- 통신망

## 4. Strategic position

Senior Trust Gateway가 모든 일을 직접 하는 서비스가 되는 것은 목표가 아니다.

> **어떤 서비스에 무엇을 맡겨도 되는지 판단하고, 필요한 권한만 안전하게 연결하는 레이어**

이 위치를 유지하면 외부 AI가 강해질수록 경쟁만 늘어나는 것이 아니라 사용할 수 있는 실행 인프라도 함께 늘어난다.
