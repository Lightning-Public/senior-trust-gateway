# 모두의 AI 실험실 클라우드 신청 화면 관찰 기록

Last updated: 2026-09-05

## 상태

사용자가 `aitestbed.kr`에 실제 로그인한 뒤 **클라우드 신청** 화면까지 진입하여 직접 확인한 항목을 기록한다.

## 실제 화면에서 확인한 항목

- 필수 입력: `프로젝트명`
- 필수 입력: `이용기간`
- 필수 입력: `이용목적` (최대 500자)
- 추천 클라우드 사양: **vCPU 2EA / Memory 4GB / Disk 50GB**
- 추천 운영체제: **rocky-8.10-base**
  - OS 유형: LINUX
  - OS 종류: ROCKY
  - OS 버전: rocky-8.10-base
- 기본 지원 안내: **1개월 우선 지원**
- 연장이 필요한 경우 종료 2주 전부터 `마이스튜디오 > 클라우드 > 신청함 - 승인자원`에서 프로젝트 선택 후 `연장신청하기` 가능
- 2026년 클라우드는 **1인당 1회 신청 가능**
- 신청 종료(반납) 사용자는 연말까지 재신청 불가 안내가 표시됨

## `AI 안심매니저` 신청 권장값

- 프로젝트명: `AI 안심매니저`
- 이용기간: 공모전 실증과 후속 프로토타입 검증을 위해 **가능한 가장 빠른 시작일 + 1개월**
- 이용목적:

> 시니어가 의심 문자와 디지털 요청을 안전하게 판단하도록 돕는 `AI 안심매니저` 프로토타입을 개발·검증합니다. 규칙엔진은 송금·인증번호·앱 설치·원격제어 등 고위험 행동을 결정론적으로 차단하고, AI는 애매한 문자 의도·사칭 맥락 분석과 60대 이상 사용자가 이해하기 쉬운 설명 생성을 담당합니다. 모델 장애·지연·잘못된 응답 시 규칙엔진으로 안전하게 fallback하는 구조를 테스트하며, 개인정보·문자 원문·API 키는 저장하지 않습니다.

## 아직 확인하지 않은 항목

이 화면만으로는 아래를 확인했다고 주장하지 않는다.

- 정확한 AI 모델 표시명
- 바이브코딩 토큰 발급/할당 방식
- 모델 API/SDK endpoint
- 미리보기/배포 기능
- 클라우드 신청 즉시 승인 여부

다음 증빙은 클라우드 신청 완료 화면 또는 마이스튜디오 승인/대기 화면에서 이어서 기록한다.
