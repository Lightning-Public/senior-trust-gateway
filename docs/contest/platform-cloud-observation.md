# 모두의 AI 실험실 클라우드 신청 화면 관찰 기록

Last updated: 2026-09-05

## 목적

이 문서는 `aitestbed.kr`에서 실제 확인한 **플랫폼 사실**만 기록한다.

이 클라우드 신청 자체가 `senior-trust-gateway` MVP의 실행 조건은 아니다. 공모전 개발 우선순위는 `docs/contest/contest-harness.md`를 따른다.

## 실제 화면에서 확인한 항목

사용자가 `aitestbed.kr`에 로그인한 뒤 **클라우드 신청** 화면까지 진입했다.

- 필수 입력: `프로젝트명`
- 필수 입력: `이용기간`
- 필수 입력: `이용목적` (최대 500자)
- 추천 클라우드 사양: **vCPU 2EA / Memory 4GB / Disk 50GB**
- 추천 운영체제: **rocky-8.10-base**
  - OS 유형: LINUX
  - OS 종류: ROCKY
  - OS 버전: rocky-8.10-base
- 기본 지원 안내: **1개월 우선 지원**
- 연장이 필요한 경우 종료 2주 전부터 `마이스튜디오 > 클라우드 > 신청함 - 승인자원`에서 프로젝트 선택 후 `연장신청하기` 가능
- 2026년 클라우드는 **1인당 1회 신청 가능**
- 신청 종료(반납) 사용자는 연말까지 재신청 불가 안내가 표시됨

## 공모전 서비스 명칭

- 프로젝트명: **시니어 AI 생활매니저**
- 부제: **안심부터 시작하는 시니어 디지털 동행**
- MVP 메인: Trust Check
- MVP 확장: Hospital Kiosk Safe Guidance

## 클라우드 신청용 이용목적

> 고령자가 문자·키오스크 등 일상 디지털 서비스를 안전하게 이용하도록 돕는 시니어 AI 생활매니저를 개발·검증합니다. AI는 복잡한 문맥을 쉽게 설명하는 역할을 하고, 송금·인증정보·앱 설치·개인정보·결제 등 고위험 상황은 규칙 기반 안전정책과 사람 확인 절차로 보호합니다. 모두의 AI 실험실 플랫폼 활용을 통해 MVP와 공모전 제출 증빙을 검증합니다.

## 아직 확인하지 않은 항목

이 화면만으로는 아래를 확인했다고 주장하지 않는다.

- 클라우드 신청 완료/승인 상태
- 정확한 AI 모델 표시명
- 외부 AI 추론 API/SDK endpoint
- 모델 quota
- image input capability
- 미리보기/배포 기능

위 항목은 실제 화면이나 공식 문서에서 확인된 경우에만 별도 기록한다.
