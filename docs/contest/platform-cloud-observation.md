# 모두의 AI 실험실 클라우드 신청 화면 관찰 기록

Last updated: 2026-09-05

## 상태

사용자가 `aitestbed.kr`에 실제 로그인한 뒤 **클라우드 신청** 화면까지 진입하여 직접 확인한 항목을 기록한다.

## 실제 화면에서 확인한 항목

- 필수 입력: `프로젝트명`
- 필수 입력: `이용기간`
- 필수 입력: `이용목적` (최대 500자)
- 추천 클라우드 사양: **vCPU 2EA / Memory 4GB / Disk 50GB**
- 추천 운영체제: **rocky-8.10-base**
  - OS 유형: LINUX
  - OS 종류: ROCKY
  - OS 버전: rocky-8.10-base
- 기본 지원 안내: **1개월 우선 지원**
- 연장이 필요한 경우 종료 2주 전부터 `마이스튜디오 > 클라우드 > 신청함 - 승인자원`에서 프로젝트 선택 후 `연장신청하기` 가능
- 2026년 클라우드는 **1인당 1회 신청 가능**
- 신청 종료(반납) 사용자는 연말까지 재신청 불가 안내가 표시됨

## 공모전 서비스 명칭 결정

- 공모전/클라우드 프로젝트명: **시니어 AI 생활매니저**
- 설명용 부제: **안심부터 시작하는 시니어 디지털 동행**
- Phase 0 핵심 기능: 의심 문자·디지털 요청 `Trust Check`
- 확장 장면: `Kiosk Safe Guidance`
- 장기 제품 구조: `Protect → Trust → Delegate`

`AI 안심매니저`는 제품 전체명이 아니라 초기 Trust Check 기능을 설명하는 표현으로 사용한다.

## 클라우드 신청 권장값

- 프로젝트명: `시니어 AI 생활매니저`
- 이용기간: 공모전 실증과 후속 프로토타입 검증을 위해 **가능한 가장 빠른 시작일 + 1개월**
- 이용목적:

> 고령자가 문자·키오스크 등 일상 디지털 서비스를 안전하게 이용하도록 돕는 `시니어 AI 생활매니저`를 개발·검증합니다. AI는 문자와 화면의 의도·맥락을 이해해 쉬운 설명과 다음 행동을 제공하고, 송금·인증정보·앱 설치·개인정보·결제 등 고위험 상황은 규칙 기반 안전정책과 사람 확인 절차로 보호합니다. 모두의 AI 실험실 AI·클라우드 환경을 활용해 Trust Check와 Kiosk Safe Guidance를 하나의 생활지원형 AI 서비스로 실증합니다.

## 아키텍처 연결

- Senior Trust Gateway = 위험·검증·권한정책 본체
- `Lightning-Public/kiosk_ar_assistant@3a7da8f` = 화면·음성·포인터 UX 원본
- aitestbed AI = 공통 `AIProvider`를 통한 문맥 이해·쉬운 설명
- 모델/API 호출 = 서버 측 경로 우선
- 개인정보/문자 원문 = 최소화·마스킹
- quota / timeout / 잘못된 JSON / 모델 장애 = 결정론적 fallback

## 아직 확인하지 않은 항목

이 화면만으로는 아래를 확인했다고 주장하지 않는다.

- 정확한 AI 모델 표시명
- 바이브코딩 토큰 발급/할당 방식
- 모델 API/SDK endpoint
- image input capability
- 미리보기/배포 기능
- 클라우드 신청 즉시 승인 여부

다음 증빙은 클라우드 신청 완료 화면 또는 마이스튜디오 승인/대기 화면에서 이어서 기록한다.
